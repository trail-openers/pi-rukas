### Assumptions
- The D1/D2 deterministic-await approach is the better fix (vs. ≥30 s budget) because it's structurally correct (no wall-clock dependence) and keeps the passing path fast. The ≥30 s budget is the fallback if the seam proves too invasive — either satisfies the acceptance criteria. Defensible default: prefer the minimal production change (return a promise from `writeLensLedgerEntry`, no new public API surface on `LensReviewSummary`).
- The test-only seam in `finish()` is implemented as a module-level handle (e.g., `let __lensLedgerPending: Promise<void> | null = null`) that tests can `await` directly — NOT a new exported function with a run-id argument (simpler, no new public API). Defensible default: minimal surface area.
- The T8 ceiling fix raises `TIMING_CEILING_MS` to a fixed multi-second constant (e.g., `10_000` ms) rather than scaling with `MAX_OUTER_CALLS` — simpler, and the exact-count assertion is the real regression detector. Defensible default: the ceiling is a safety net, the count is the signal.
- D7 (shared helper lift) is optional; if the implementer keeps the helpers local, both files get the ≥30 s budget independently. Defensible default: don't add a shared module unless the duplication is actively painful.
